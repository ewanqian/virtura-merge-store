# Commercial Scope & Pricing Boundary

Status: internal commercial framework
Owner: Manager / A1 Product

This document defines how VIRTURA should quote productization projects. It is not a fixed public price list.

## Rule 01 — separate creative fees from production costs
Never hide manufacturing risk inside one vague all-in creative quote.

### Creative / design fee may include
- project interpretation
- product concept development
- SKU family direction
- industrial / visual design
- interaction logic
- prototype design
- packaging direction
- supplier-ready design files
- case / launch art direction where contracted

### Engineering / prototype fee may include
- electronics architecture
- firmware / software prototype
- 3D print / workshop iteration
- interaction testing
- DFM coordination

### Third-party / production costs are separate
- tooling / molds
- samples
- materials
- unit manufacturing
- packaging printing
- certification/testing if required
- freight
- warehousing
- fulfillment
- payment/platform fees
- taxes where applicable

## Rule 02 — production management is a service
If VIRTURA is expected to manage suppliers after design approval, quote production management separately.

Possible models to test internally:
- fixed project management fee
- monthly production management retainer
- percentage of managed third-party production spend
- hybrid minimum + percentage

Do not publish a percentage until validated against real projects.

## Rule 03 — revision limits
Suggested default structure:
- Direction stage: 2 consolidated revision rounds
- Product design stage: 2 consolidated revision rounds per selected direction
- Packaging stage: 2 consolidated revision rounds
- Sample revision: one correction cycle included only if the cause is a design-side issue within agreed scope

Changes after a signed gate become change orders.

## Rule 04 — approval gates
G0 Brief locked
G1 Direction selected
G2 Prototype behavior approved
G3 Supplier/DFM feasibility approved
G4 Sample approved
G5 Packaging proof approved
G6 Production release

Client changes after G4 may cause re-sampling/tooling cost and schedule change.

## Rule 05 — proposal exclusions must be explicit
Unless included, proposals should state that these are excluded:
- trademark / patent legal searches
- formal regulatory certification
- customs/import compliance
- retail channel negotiation
- warehouse operation
- customer support
- media buying
- ongoing software hosting
- blockchain issuance / legal compliance

## Rule 06 — source files and IP
Proposal must state:
- what final production files are handed over
- what reusable VIRTURA tools/frameworks remain VIRTURA IP
- whether editable/source files are included
- whether firmware/source code is licensed or assigned
- portfolio/publication rights subject to NDA/client approval

## Rule 07 — concept fee is not free pitching
For clients asking for detailed product concepts before engagement, use one of:
- paid discovery / concept sprint
- limited indicative direction with no production-ready details
- credit the discovery fee toward later full project if contracted

## Internal package logic
### A — Cultural Product Capsule
Best when the client needs a coherent 3–5 SKU family and packaging system.

### B — Interactive Object Edition
Best when one distinctive physical/digital hero object is the commercial or PR centerpiece.

### C — Retail + Activation System
Best when merchandise, display, interaction and launch experience must be one system.

## Quote architecture
A client-facing quote should read in this order:
1. objective
2. scope
3. deliverables
4. schedule / gates
5. creative fee
6. prototype/engineering fee
7. estimated third-party costs
8. optional production-management fee
9. exclusions
10. payment milestones
11. change-order rule
12. IP / source file / portfolio terms

## Manager principle
VIRTURA sells judgement, translation, design and execution management. Supplier invoices should not be confused with creative value, and creative fees should not be used to silently absorb supply-chain uncertainty.
