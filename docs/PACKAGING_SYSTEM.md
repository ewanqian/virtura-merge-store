# MERGE Packaging System v0.1

## Objective
Create one packaging language that can scale from low-cost utility goods to premium collectible objects without becoming generic branded merch.

## Architecture
Every package should be composed from the same hierarchy:

1. **Outer protection** — shipping / retail protection
2. **Object container** — box, sleeve or pouch
3. **Object locator** — tray, folded card, foam/EVA only where necessary
4. **Identity layer** — object code, edition, serial, QR/NFC
5. **Information layer** — object story, instructions, care, technical state

## Visual language
- warm off-white / graphite / black
- Chinese Song-style serif for short editorial statements
- English sans-serif / monospace-like small technical labels
- one object code always visible
- no decorative cyberpunk UI
- no excessive foil, holographic film or RGB-tech styling
- materials and construction should look credible at the target price point

## Shared label format

`VIRTURA / MERGE`

`OBJECT: FLOW BLOCK`

`CODE: OBJ-007`

`SERIAL: FLB-26-0047`

`STATE: SAMPLE / EDITION / IN STOCK`

`MADE: 2026`

Optional QR points to the Object Passport / product page. NFC is optional and should not be used unless it improves the experience.

## Package tiers

### U / Utility
For PATCH / LABEL SYSTEM and low-cost accessories.

- folded technical card or slim envelope
- single-color or two-color print
- die-cut window only if useful
- hook/loop or product can be seen without premium rigid box
- target: low material waste, fast packing

### C / Compact object
For SIGNAL KEY SET.

- small folding carton or drawer-style carton
- removable paper-pulp / folded-board locator preferred before foam
- keycap / electronics unit separated where needed
- quick-start card
- battery / electronic warnings only if required by final hardware

### P / Premium collectible
For FLOW BLOCK / DROP FLOW / limited editions.

- rigid box or high-quality folding structure
- object protected from optical-surface scratching
- microfiber / paper wrap only if necessary
- serial card + edition statement
- minimal reveal sequence: lid → object → one information layer

## Insert card
Front:
- object name CN / EN
- one-sentence concept

Back:
- object code
- serial / edition
- material
- care / operating note
- QR / passport link
- production status

## Copy rule
Never write `LIMITED EDITION`, `HANDMADE`, `MADE IN...`, material claims or sustainability claims unless they are factually verified for that batch.

## Proof products

### FLOW BLOCK
Premium optical/material sample. Packaging must prove VIRTURA can handle gallery-shop / museum-shop quality.

### SIGNAL KEY SET
Compact technical object. Packaging must explain interaction in under 20 seconds.

### PATCH / LABEL SYSTEM
Low-cost utility pack. Packaging must demonstrate production discipline without over-packaging.

## Packaging approval gate
Before production:
- dieline reviewed
- object dimensions frozen
- transit protection tested
- required regulatory / caution copy checked
- print proof approved
- serial/SKU logic tested
- packed unit photographed and archived
