# Commercial Collaboration Strategy — MERGE / VIRTURA

## Objective
Use MERGE as evidence that VIRTURA can translate cultural/creative concepts into products that are conceptually distinctive, manufacturable, photographable, interactive and commercially deployable.

## Evaluation criteria
Score every product idea against five commercial signals:
1. **Brief fit** — can a museum / exhibition / festival / artist / brand easily adapt it to their content?
2. **Production clarity** — can it move from render to sample to small batch without a long R&D cycle?
3. **Retail legibility** — does a customer understand the object in 3–5 seconds?
4. **Campaign value** — can it generate strong photography, short video, installation or launch content?
5. **System leverage** — can the same platform be reused across multiple clients rather than rebuilt once?

## Priority tiers

### Tier A — Build first for commercial collaboration

#### 1. SIGNAL KEY SET / Custom Input Object
**Commercial role:** strongest proof of VIRTURA's unique productization ability.

Why:
- can be reskinned for artists, festivals, exhibitions and brands
- combines object design + 3D printing + electronics + sound interaction + software
- can become a giveaway, retail edition, installation interface or show-control device
- highly demonstrable in a 10–20 second video

Client variants:
- artist edition keycaps
- museum collection symbols
- event states / cue keys
- branded sonic signatures
- audience participation kits

Deliverable package:
`concept → keycap system → acoustic protocol → prototype electronics → receiver demo → packaging → short film`

#### 2. PATCH / LABEL / OPERATOR SYSTEM
**Commercial role:** fastest path to real small-batch production and visible delivery capability.

Why:
- low tooling / relatively low MOQ
- easily adapted to exhibitions, festivals, artist tours, internal event crews and retail
- can grow from patch to tags, labels, lanyards, bag systems and packaging accessories
- useful rather than generic logo merchandise

Best use: first real manufactured SKU and fulfillment case study.

#### 3. FLOW OBJECT FAMILY
Includes DROP FLOW, FLOW BLOCK, FLOW TAG.

**Commercial role:** strongest cultural / museum / art retail family.

Why:
- a single visual language can scale from ¥100 accessory to ¥500 desktop object to installation-scale work
- can absorb client-specific themes without becoming logo merchandise
- glass/acrylic/resin/light/fluid provide strong photography and gift-shop display value
- easy to create limited editions and material variants

Best strategy: sell it as a **family**, not isolated products.

#### 4. TIMER / REWIND
**Commercial role:** hero collectible and campaign object.

Why:
- strong one-line concept
- good for limited editions, artist collaborations, design fairs and museum shops
- physical + digital twin gives VIRTURA a differentiated story

Risk:
- custom electronics/enclosure require more engineering than patches or optical objects.

### Tier B — Build as capability proof / upsell

#### 5. SYNC OBJECT
High value for brand activation, music and experiential projects, but weaker as an immediately understandable retail object until its behavior is polished.

Best use:
- activation giveaway / table object
- sound-reactive brand experience
- show-linked edition
- installation node

#### 6. HOURGLASS 10
Easy to understand and visually strong but less defensible by itself. Best used as a collaboration canvas with custom material, sand, time interval, engraving or packaging.

### Tier C — keep as digital R&D, not first commercial proof
- LIQUID FIELD
- TIME RESIDUE
- GRAVITY STUDY

These strengthen VIRTURA's digital-object identity but do not prove supply-chain delivery alone.

## Recommended portfolio case-study structure

Do not present MERGE as “we designed some merch.” Present it as:

### VIRTURA — Concept → Object → Production
1. **Interpret** — extract a project / exhibition / artist's core behavior, not just graphics.
2. **Translate** — turn that behavior into an object mechanic, material or interaction.
3. **Prototype** — render / CAD / 3D print / electronics / web simulation.
4. **Produce** — supplier, sample, DFM, MOQ, QC, packaging.
5. **Activate** — store page, product film, physical display, digital twin / interaction.
6. **Fulfil** — low inventory, edition tracking, shipping and optional Object Passport.

## Commercial packages

### A. CULTURAL PRODUCT CAPSULE
3–5 SKUs, visual/product concept, packaging and supplier-ready files.
Target: museums, exhibitions, artists, festivals.

### B. INTERACTIVE OBJECT EDITION
One hero object with electronics / sensor / sound / light / web interaction.
Target: technology brands, music events, launches, experiential campaigns.

### C. RETAIL + ACTIVATION SYSTEM
Product family + pop-up/display + interactive demo + launch assets.
Target: larger brands and institutions.

## What must be built to prove this capability
1. One **real manufactured low-risk object**: SIGNAL KEY SET shell/keycap or PATCH SET.
2. One **material-led premium object**: FLOW BLOCK / DROP FLOW sample.
3. One **electronic interactive prototype**: SIGNAL KEY SET receiver or SYNC OBJECT.
4. One **finished packaging system** with insert, serial, barcode/QR and edition logic.
5. One **60–90 second case film** showing concept → prototype → production → interaction.
6. One **client adaptation page** showing the same platform reinterpreted for three hypothetical briefs.

## Current recommendation
The strongest commercial trio is:

**SIGNAL KEY SET + FLOW OBJECT FAMILY + PATCH / LABEL SYSTEM**

Together they demonstrate:
- interaction / electronics
- material / collectible design
- scalable low-risk production

TIMER and SYNC OBJECT should remain hero R&D pieces that raise the perceived ceiling of VIRTURA's capability.
