# MERGE Commercial Case Film — 60–90 sec

## Purpose
This is not a mood film. It is a sales proof showing that VIRTURA can translate cultural or project content into a designed object, prototype it, prepare it for production, package it and activate it.

## Master structure

### 00–08 sec — INPUT
Show project / performance / cultural source material.

On-screen:
`FROM SYSTEMS, PERFORMANCES AND CULTURAL CONTENT.`

Chinese:
`从项目内容中提取行为，而不是贴上一个标志。`

### 08–18 sec — INTERPRET
Fast sequence of notes, diagrams, extracted words, behaviors and material references.

Examples:
- REWIND → reversible timer
- FLOW → optical gravity object
- LIVE / HOLD → operator key system

On-screen:
`INTERPRET`

### 18–32 sec — TRANSLATE
Product renders, physical scale decisions, 3D models, interaction diagrams.

Show the three proof products:
- SIGNAL KEY SET
- FLOW BLOCK
- PATCH / LABEL SYSTEM

On-screen:
`CONCEPT → OBJECT BEHAVIOR`

### 32–48 sec — PROTOTYPE
Real prototype footage only where available:
- 3D-printed keycap
- acoustic key test
- microphone detection
- material/optical sample
- patch sample
- failure/revision details

On-screen:
`PROTOTYPE / TEST / REVISE`

### 48–62 sec — PRODUCE
Supplier RFQ, drawing excerpt, material swatch, sample inspection, packaging proof.

Avoid showing private supplier pricing or confidential vendor information.

On-screen:
`SPECIFY / SAMPLE / QC`

### 62–74 sec — PACKAGE
Box, insert, serial, object code, QR/passport layer.

On-screen:
`OBJECT / EDITION / IDENTITY`

### 74–86 sec — ACTIVATE
Three rapid client-context adaptations:
- museum / cultural institution
- music festival / live event
- technology / automotive brand

On-screen:
`ONE SYSTEM, DIFFERENT CONTEXTS.`

### 86–90 sec — END
`VIRTURA`
`CONCEPT → OBJECT → PRODUCTION`
`概念制品化 / 创意产品化`

## Required capture list

### Product
- clean hero still/video of each proof product
- in-hand / scale shot
- close material detail
- interaction shot

### Process
- sketch / diagram
- CAD / 3D viewport
- 3D print or workshop step
- RFQ/spec sheet glimpse
- sample inspection
- revision/failure comparison

### Packaging
- open / reveal
- serial label
- insert card
- object placement

## Truth rule
Render footage can represent design intent, but any claim about manufacturing, supplier output, materials, batch quantity or fulfillment must be supported by real evidence.

Use clear labels where useful:
`CONCEPT RENDER`
`WORKING PROTOTYPE`
`SUPPLIER SAMPLE`
`PILOT`

## Cutdowns

### 15 sec
Input → three objects → one prototype → packaging → service line.

### 6–10 stills
Extract frames suitable for:
- proposal cover
- capability deck
- website
- social announcement

## Editing language
- restrained sound design
- no generic glitch/cyberpunk transitions
- macro material audio is useful
- interface states should feel like instrumentation, not HUD decoration
- typography should match the MERGE store: Chinese serif editorial layer + small English system labels
