# MERGE — Public project status

Updated: 2026-11-20 · public-facing summary (not a live production dashboard).

MERGE is a VIRTURA prototype and productization research programme. Public demonstrations include interactive digital-object concepts, store/proposal UI and selected hardware design studies. This repository does **not** establish that physical units are in stock, supplier contracts have been completed or paid commerce is live.
