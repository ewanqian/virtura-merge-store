## Commercial positioning
**Concept → Object → Production**  
**概念制品化 / 创意产品化**

VIRTURA's value is not generic merchandise design. The service begins by extracting a behavior, material, structure or ritual from a project and converting it into an object that can be prototyped, manufactured, packaged and activated.

## Commercial truth standard
Public status language is constrained to:
- CONCEPT
- PROTOTYPE
- SAMPLE
- PILOT
- EDITION
- IN STOCK

Do not represent renders as samples, successful samples as production capacity, concept prices as live prices, or future supplier relationships as existing capability.

## Architecture decision
