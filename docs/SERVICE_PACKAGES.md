# VIRTURA Productization Service Packages

Working positioning:

**Concept → Object → Production**  
**概念制品化 / 创意产品化**

These are service structures, not fixed public prices. Manufacturing, tooling, freight and third-party supplier costs should be separated from creative/service fees.

## Package A — Cultural Product Capsule
For museums, exhibitions, artists, hotels, cultural institutions and IP projects that need a coherent small product family.

### Includes
- brief + content interpretation
- one product-language direction
- 3–5 SKU concepts
- product naming / object-code system
- visual/material direction
- prototype-ready design definition
- basic packaging family
- supplier-ready handoff package for selected SKUs
- launch/store presentation direction

### Typical outputs
- 3–5 product briefs
- renders / mockups
- dimension/material specification for selected products
- packaging concept
- RFQ-ready files where scope includes production preparation

### Excludes by default
- tooling
- supplier invoices
- mass production
- freight / warehousing
- legal licensing clearance
- marketplace operation

## Package B — Interactive Object Edition
For technology brands, festivals, artists and exhibitions that need one recognizable hero object with behavior.

### Includes
- interaction concept
- physical/digital behavior system
- hardware/software prototype plan
- enclosure/product direction
- one working proof where technically feasible within scope
- digital interaction/demo layer
- packaging + edition identity
- supplier/engineering handoff package
- launch demo / filming direction

### Best fit
SIGNAL KEY SET, SYNC OBJECT, TIMER / REWIND-like commissions.

## Package C — Retail + Activation System
For larger brand launches, festivals, exhibitions or destination projects that need products, display and interaction to behave as one system.

### Includes
- product family architecture
- hero object + utility/accessible price tiers
- packaging system
- retail/display direction
- digital interaction or object-passport layer
- launch/activation behavior
- supplier coordination structure
- case-film / campaign asset direction

### Optional extensions
- spatial installation
- WebXR / browser interaction
- event control integration
- numbered edition / VIP gift system
- ongoing production management

## Commercial structure
Recommended proposal separation:

1. Creative / direction fee
2. Prototype / engineering fee
3. Supplier / tooling / sample costs
4. Manufacturing cost
5. Packaging production
6. Freight / fulfillment
7. Optional production-management fee
8. Optional launch / activation production

This avoids hiding manufacturing risk inside one creative quote.

## Client inputs required
- project/IP background
- approved assets and licensing boundaries
- target audience
- target quantity
- launch date
- retail / gifting / activation purpose
- price target or budget band
- geography / fulfillment requirement
- required approval stakeholders

## Revision principle
Direction approval should happen before supplier/sample work. Changes after sample approval may require a change order because tooling, materials or packaging may already be committed.

## Positioning sentence
VIRTURA does not begin by asking which logo should be printed on an object. We begin by identifying what behavior, material, structure or ritual from the project can become an object worth keeping.
