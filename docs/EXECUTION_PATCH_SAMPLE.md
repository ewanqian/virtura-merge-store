# PATCH / LABEL SYSTEM — First Manufactured Sample Pack

Status: P0 commercial proof
Owner: A7 Supply Chain / A9 Creative
Object: OBJ-004 OPERATOR PATCH SET

## Objective
Create the fastest real manufacturing proof in MERGE: a small batch of professionally finished operator/status patches that can be photographed, packaged, sold as utility objects and shown to clients as evidence of production execution.

## First set
Recommended 9-piece family:
- LIVE
- HOLD
- READY
- SYNC
- OSC
- DMX
- EXIT
- ERROR
- 00:30 / 01:00 as alternate timed states

Do not make them military/tactical cosplay objects.

## Construction routes to quote
1. molded soft PVC + hook backing
2. printed PVC + hook backing
3. woven / embroidered label only as cost comparison, not primary aesthetic

## Size system
Keep one system, not nine arbitrary shapes.

Recommended starting families:
- square: 45 × 45 mm
- horizontal: 65 × 30 mm
- compact label: 48 × 22 mm

Use 2–3 master formats maximum.

## Visual target
- matte black / graphite base
- off-white / warm-gray information
- restrained microtype
- raised or recessed marks only where legibility improves
- no high-saturation accent unless a client version requires it

## Supplier files
Prepare:
- vector artwork
- positive/negative mold view
- dimensions
- backing requirement
- edge treatment
- color reference
- packaging count
- version code

## RFQ ladder
Request:
- sample / tooling fee
- 20 sets
- 50 sets
- 100 sets
- 500 sets

Record whether pricing is per piece or per complete set.

## Acceptance checklist
- no visibly warped edges
- lettering readable at arm's length
- matte/rubber finish consistent
- hook backing bonded/sewn cleanly
- no strong chemical smell after reasonable airing
- color deviation acceptable against approved reference
- pack count / label count correct

## Packaging V0
- flat card or folded sleeve
- one object-code label
- contents map
- status vocabulary explanation
- no oversized rigid box

## Evidence
Document:
`artwork → quote → sample → rejected detail → revised sample → final pack`

This case is intentionally less technically ambitious than SIGNAL KEY. Its job is to prove manufacturing discipline.
