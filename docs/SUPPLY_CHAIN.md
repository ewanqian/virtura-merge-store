# Supply Chain Strategy

## Default model
Small-batch production + low inventory + single-order fulfillment.

## Priority categories
1. PVC hook-and-loop patches
2. acrylic / optical objects
3. timer / hourglass shells
4. ESP32-S3 programmable lights
5. packaging / nameplates / NFC labels

## Vendor matrix
Track: MOQ / sample fee / tooling / unit cost / lead time / packaging / warehouse support / QC / IP/confidentiality / replacement policy.

## Initial stock policy
- Patches: 50–100 after sample approval
- Electronics: 5–20 prototypes before custom PCB
- Optical/fluid objects: 5–10 samples across structures

Do not assume molded PVC is efficient as true made-to-order; sample first, then hold a small approved stock.
