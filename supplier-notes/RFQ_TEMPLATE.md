## Sample acceptance checklist
A sample is not approved until the following are checked:

### Form
- dimensions match drawing
- assembly fits correctly
- no visible warping / cracks / unexpected seams

### Finish
- material matches spec
- color within agreed tolerance
- surface finish consistent
- printed / engraved marks aligned and legible

### Function
- moving / electronic / acoustic behavior verified
- switch / connector / battery access works
- repeated-use test passed where applicable

### Packaging
- object protected in transport orientation
- insert does not scratch finish
- edition / SKU / QR placement correct

### Documentation
- sample version photographed
- supplier and date recorded
- pass/fail/revision decision written
