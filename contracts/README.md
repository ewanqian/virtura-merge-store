# Conflux Passport — Testnet only

Target: **Conflux eSpace testnet**.

Initial behavior:
- optional claim/issue of a non-financial Object Passport
- associate Passport metadata with a MERGE Object ID
- verify ownership/claim state
- no marketplace UI
- no yield
- no investment framing
- no RWA/property-right representation
- no public paid issuance until legal/compliance review

Implementation is intentionally deferred until M4. The internal Object Registry must work first.
