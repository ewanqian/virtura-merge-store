# VIRTURA MERGE / Virtual Merchandise Store

**Status:** Prototype / pre-production  
**Owner:** VIRTURA  
**Working title:** MERGE — Goods for Reality  
**Scope:** Physical objects, digital objects, phygital editions, utility objects.

MERGE is not a generic merch shop. It turns visual systems, performances and experiments into collectible, usable, programmable objects.

## Current product families

- **OBJ-001 — SYNC OBJECT** — programmable light object; ESP32-S3 + microphone + addressable LED.
- **OBJ-002 — TIMER / REWIND** — physical timer + digital/spatial twin; forward / rewind states.
- **OBJ-003 — DROP FLOW / ∞** — continuous-flow physical/digital object.
- **OBJ-004 — OPERATOR PATCH SET** — PVC hook-and-loop utility patches.
- **DIG-001 — LIQUID FIELD** — digital-only interactive object.
- **DIG-002 — TIME RESIDUE** — digital-only temporal/spatial object.
- **DIG-003 — GRAVITY STUDY** — digital-only orientation-reactive object.

## Principles

1. The object must be desirable even without project context.
2. The project concept must materially affect the object's function, behavior or structure.
3. Digital editions are first-class products, not downloadable bonuses.
4. Physical + digital twins share one Object ID where applicable.
5. Blockchain is optional infrastructure for verification, not the product itself.
6. No speculative resale, floor-price framing, investment claims or RWA tokenization in the initial system.
7. Visual language: precise, quiet, minimal, materially credible.

- **P1 — Product Prototypes:** physical samples + interactive digital twins + Object Registry.
- **P2 — Commerce:** RMB payments, fulfillment, customer accounts, store policies.
- **P3 — Passport:** optional Conflux-backed Object Passport after technical/legal review.
